# Meal Stripper — retirement note

Meal Stripper is superseded by **Meal Buffet**, which contains the same
one-click meal strip (`Clear meal`) plus the whole meal picker. Paste the blocks
below on the Meal Stripper Nexus page, then either hide the mod or mark it as
retired and point to Meal Buffet.

Nexus BBCode (description update, paste at the very top of the description):

```
[size=5][b]Retired — use Meal Buffet instead[/b][/size]

[b]Meal Buffet[/b] replaces this mod. It contains the same one-click meal strip (the [b]Clear meal[/b] button) and adds a full meal picker: choose any canteen meal, pick or reroll the two extra buffs, apply it anywhere — in the hub, at camp or during a quest — with no voucher and no ingredients.

Applying a new meal also replaces the active one directly, so you no longer need to strip and re-eat.

Remove this mod before installing Meal Buffet.

[url=https://github.com/Diegoeyza/meal-buffet]Source and downloads: Meal Buffet[/url]
```

Short description replacement:

```
RETIRED — replaced by Meal Buffet. One-click meal strip is now the "Clear meal" button there, plus a full meal picker.
```

After updating the page:
1. Set the old file to the previous version and remove it from the main file slot,
   or hide the mod page entirely.
2. Do not delete the page: existing users should land on the retirement notice.
